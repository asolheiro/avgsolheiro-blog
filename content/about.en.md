## Overview

I am a professional focused on Backend Software Development and Operations Support. Passionate about open source, innovation, and my unique approach to doing things. With solid experience in Go and Python for development and Docker, Kubernetes, and Helm for implementing DevOps, I am always seeking challenges and new technologies that allow me to grow, become a more complete professional, and contribute to the success of the teams and companies with which I collaborate.

## 👨🏽‍💻 Software Development Expertise

- **Go**: Comprehensive experience with backend development, automation, CLIs, gRPC, and API construction.
- **Python**: Experience with backend development, automation, building scalable APIs using FastAPI and Django.
- **Java**: Experience with backend development, building APIs using Spring Boot/Framework.

## 🛞 DevOps Culture

- **Docker**: Creation and management of containers for consistent development environments.
- **Kubernetes**: Large-scale container orchestration to ensure high availability and resilience.
- **Helm**: Package manager for Kubernetes that facilitates the installation and updating of applications through pre-configured charts.
- **ArgoCD**: Declarative continuous delivery (CD) tool for Kubernetes that automates application deployment following the GitOps paradigm.
- **Prometheus**: Open-source monitoring and alerting system that collects and stores metrics in a time-series database.
- **GitOps**: Methodology that uses Git as the single source of truth for declarative infrastructure, automating the deployment and synchronization of environments with repositories.
