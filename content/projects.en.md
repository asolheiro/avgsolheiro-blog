# Personal Projects

## 📚 Documentation

- [GitaDocs](https://github.com/GitaCloudTeam/gita-doc): Documentation of Gita created with Docusaurus

## ⚙️ DevOps

- [Desafio JackExperts](https://github.com/asolheiro/desafio-jackexperts): Project I used to join JackExperts, packaging an application using Helm, deploying on the Kubernetes cluster at MagaluCloud through a pipeline on GitHub actions.
- [DevOps Manifests](https://github.com/asolheiro/DevOpsManifests-examples): Result of my DevOps studies, examples of manifests for the community to use

## 🦫 Go

- [GHC](https://github.com/asolheiro/ghc): Command-line tool to generate reports that I needed to do manually every day on Gita. The repository includes a pipeline for release distribution and has versions for GitHub and GitLab.
- [GTW-CC](https://github.com/asolheiro/gtw-cc): Challenge to consume and integrate Binance and Huobi APIs
- [Kiosk API](https://github.com/asolheiro/kiosk-api): Go version of an API used for event registration. It integrates with a Flutter frontend and a Zebra printer.
- [PLS-GO](https://github.com/asolheiro/pls-go): CLI I use daily to manage tasks in my terminal. Go version of the [pls-cli](https://github.com/guedesfelipe/pls-cli) project

## ☕️ Java

- [rest-with-springboot](https://github.com/asolheiro/rest-with-springboot): Complete RESTful API environment. Developed as a way to learn and deepen my knowledge in Java
