# Projetos pessoais

## 📚 Documentação

- [GitaDocs](https://github.com/GitaCloudTeam/gita-doc): documentação do Gita feita com Docusaurus

## ⚙️ DevOps

- [Desafio JackExperts](https://github.com/asolheiro/desafio-jackexperts): projeto que utilizei para entrar na JackExperts, empacotamento de uma aplicação utilizando Helm, deploy no cluster Kubernetes na MagaluCloud a partir de uma pipeline no GitHub actions.
- [DevOps Manifests](https://github.com/asolheiro/DevOpsManifests-examples): Fruto dos meus estudos de DevOps, exemplos de manifestos para a comunidade consumir.

## 🦫 Go

- [GHC](https://github.com/asolheiro/ghc): Ferramenta de linha de comando para gerar relatórios que eu precisava realizar manualmente todos os dias no Gita. O repositório conta com pipeline para distribuição de releases, possui versões para GitHub e GitLab.
- [GTW-CC](https://github.com/asolheiro/gtw-cc): Desafio para consumo e integração das APIs da Binance e Huobi.
- [Kiosk API](https://github.com/asolheiro/kiosk-api): versão em Go de uma API utilizada para realizar o credenciamento em eventos. É integrada com um front em Flutter e uma impressora Zebra.
- [PLS-GO](https://github.com/asolheiro/pls-go): CLI que uso diariamente para gerenciar tarefas no meu terminal. Versão em Go para o projeto [pls-cli](https://github.com/guedesfelipe/pls-cli)

## ☕️ Java

- [rest-with-springboot](https://github.com/asolheiro/rest-with-springboot): API RESTful com ambiente completo. Foi desenvolvida como forma de aprendizado e aprofundamento em Java.

## 🐍 Python

- [APICultura](https://github.com/asolheiro/APIcultura): API em Python com FastAPI, meu modelo utilizado para estudos, onde testo conceitos e novas tecnologias.
- [Giropops Senhas - FastAPI](https://github.com/asolheiro/giropops-senhas-fapi): Minha versão do [GiropopsSenhas](https://github.com/badtux/giropops-senhas) em FastAPI.
- [JurisAPI](https://github.com/asolheiro/juris-python): Versão em python de um sistema que coleta inserções do usuário e produz licitações usando jinja2.
